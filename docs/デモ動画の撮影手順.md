# デモ動画の撮影手順

- 作成: 2026-10-15（意思決定ログ25）
- 作り方: **撮影は開発者が実機で、編集は Claude がコード（Remotion）で行う**。開発者は素材を3本撮って渡すだけ。字幕・時刻のカード・隠す処理・つなぎは Claude が書き出す
- 尺と流れ: 2分。DESIGN.md 10.1 の「静か → 0件で緩和の提案 → 2階以上は必須の心変わり → 内見の仮受付 → 翌朝の管理画面で確定」
- 台本: 評価セットのシナリオ `sc-01`（`eval/datasets/scenarios.ts`）と同じ。2026-10-15 に今のコード（並び順の変更・意思決定ログ24 の後）で本番の API に通して 8/8 手番が合格（$0.016）。下の表の「画面に出るもの」はその結果
- 期限: **キーを差し替えるまでは 2026-11-09 より前**。その日にいまの Anthropic の API キーが失効し、LINE の AI が返事をしなくなる（意思決定ログ21）。案件を募集する間はキーを作り直して延ばすことにした（意思決定ログ29・引き継ぎ書6章①）ので、差し替えが済めばこの期限は外れる

## いつ撮るか

撮影は2回に分かれる。夜に LINE で問い合わせ、翌朝に管理画面で確定する。

| 回 | 時間帯 | 条件 |
|---|---|---|
| 夜の部 | 21:00〜23:30 | 営業時間（既定 10〜19時・水曜定休）の外。閉店の直後と日付の変わり目は避ける |
| 朝の部 | 次の営業日の 10:00 以降 | 朝の一覧の「夜間・休日分」に夜の仮受付が載っている |

- 次の日が水曜（定休日）になる夜は避ける。つまり火曜の夜には撮らない。**おすすめは木曜の夜 → 金曜の朝**（`sc-01` の想定と同じ曜日）
- 内見の候補日は、朝の部の翌日以降で水曜でない日を1つ選ぶ（木曜の夜なら「10月17日(土)」のように土曜）。確定できるのは、内見の時刻がその日の営業時間内のときだけ（意思決定ログ14）

## 夜の部の前の準備（スマホ）

iPhone を想定して書く（Android はクイック設定の「スクリーンレコード」で同じことをする）。

1. コントロールセンターに「画面収録」を出しておく（設定 → コントロールセンター）
2. 集中モード（おやすみモードなど）で通知を止める。画面はライトモードにする
3. LINE のトーク一覧で「お部屋探しAI（デモ）」を左にスワイプして削除する。この端末の履歴だけが消え、テストの古いやりとりが映らなくなる
4. LINE の表示名を、架空の名前に一時的に変える（例: 佐藤 みなみ）。管理画面には表示名が出るため。毎朝作り直されるデモ会話の名前（山田 さくら・鈴木 健太・高橋 美咲・伊藤 翔・渡辺 優）とは別の名前にする
5. 「お部屋探しAI（デモ）」をブロックし、ブロックを解除する（ホーム → 設定 → 友だち → ブロックリスト → 編集）。解除が友だち追加として届き、表示名を取り直して会話も最初からになる（意思決定ログ5）。あいさつに「ただいま営業時間外ですが」が入っていれば、夜の部の条件どおり
6. 表示名は元に戻してよい。表示名を取り込むのは友だち追加のときだけなので、管理画面には架空の名前が残る

## 夜の部（スマホの画面収録・3〜4分）

打つ文は**このとおりに**打つ（言い回しを変えると条件の読み取りが変わることがある）。打つ速さは気にしなくてよい（編集で早送りする）。返事が届いたら、2秒ほど止まってから次へ進む（字幕を載せる間）。

| # | すること | 画面に出るもの |
|---|---|---|
| 1 | 画面収録を始め、トークを開いてあいさつを2秒映す | 「友だち追加ありがとうございます」「これはデモです」「ただいま営業時間外ですが」 |
| 2 | 打つ: `渋谷か中目黒か代官山で9万まで。バストイレ別は絶対で、静かなところがいいな` | 「条件に合う物件が7件あります」（外せない: …バストイレ別 / できれば: 静か）、カード5件（1番目はヴィラふじみ） |
| 3 | カードを左へ1枚ずつ5件目までめくり、1件目まで戻す | |
| 4 | 打つ: `あ、オートロックも絶対ほしい` | 「いまの条件では合う物件が見つかりませんでした」「オートロックを『できれば』にすると7件増えます。条件を変えますか？」 |
| 5 | 押す: 「条件を変える」 | 7件（できれば: 静か・オートロック） |
| 6 | 打つ: `やっぱり2階以上は必須` | 「条件に合う物件が5件あります」（外せない: …2階以上…）、1番目はヴィラふじみ |
| 7 | 押す: 1番目のカードの「内見を希望」 | 「『ヴィラふじみ』の内見ですね。…」、候補日のボタン |
| 8 | 押す: 朝の部の翌日の候補日（木曜の夜なら「10月17日(土)」） | 「いま 10月17日(土) をお預かりしています。…」 |
| 9 | 押す: 「この日時で送る」 | 「内見のご希望を受け付けました」「まだ予約は確定していません。ただいま営業時間外のため、○月○日に担当者から確定のご連絡をします。（デモのため、実際の連絡はありません）」 |
| 10 | 3秒映してから収録を止める | |

- 「もっと見る」は押さない
- 間違えたら、準備の 3〜5（トークの削除・架空の名前・ブロックと解除）からやり直す。名前は解除の前に架空に戻しておく
- 仮受付まで済んだ後にやり直すと、朝の一覧に前の仮受付も並ぶ。編集で切るので、却下はしない（却下すると LINE に断りの文が届き、朝の部の画面に映る）

## 朝の部（PC の録画とスマホの画面収録・1〜2分）

公開デモの文面は「デモのため、実際の連絡はありません」だが、自分の LINE の会話はデモ会話（`is_demo`）ではないので、確定すると LINE に届く。動画では開発者が担当者役をする（字幕で断る）。

準備:

- PC の録画は Xbox Game Bar を使う（Win+Alt+R で開始と停止。手前のウィンドウだけを録り、保存先は「ビデオ」→「キャプチャ」）。設定 → ゲーム → Xbox Game Bar がオンになっていること
- ブラウザはタブを1つだけにして、ブックマークバーを隠す（Ctrl+Shift+B）。ウィンドウを最大化し、表示倍率を 125% にする
- **担当者のアカウント**で https://line-rental-agent.vercel.app/admin にログインしておく（閲覧用アカウントは確定できない）。ログイン画面は録らない
- 管理画面の右上に出る担当者のメールアドレスは、編集で隠す。録るときはそのままでよい

手順:

| # | すること | 画面に出るもの |
|---|---|---|
| 1 | スマホで LINE のトークを開いたまま画面収録を始め、机に置く | |
| 2 | PC で朝の一覧（/admin）を開き、Win+Alt+R で録画を始める。「夜間・休日分」に昨夜の仮受付が出ているのを3秒映す | 架空の名前の行（ほかの行は毎朝作り直すデモ会話で「デモ」の印が付く） |
| 3 | その行を押して「内見の仮受付」を開き、希望の日時が見えるところまでゆっくりスクロールする | 物件・希望日（10月17日(土)）・受け付けた時刻 |
| 4 | 「確定する」で候補日を選び、時刻に `11:00` を入れる。ひとことは空のまま | この日の営業時間 |
| 5 | 「この日時で確定する」を押し、結果が出たら3秒映す | 確定した旨 |
| 6 | スマホに届いた文を3秒映す | 「【担当者より】『ヴィラふじみ』の内見日時が確定しました。日時: …」 |
| 7 | PC の録画（Win+Alt+R）とスマホの画面収録を止める | |

## 素材の渡し方

- 3本: 夜のスマホ・朝の PC・朝のスマホ
- iPhone の動画は、USB で PC につなぎ、エクスプローラーの「Apple iPhone」→ Internal Storage → DCIM からコピーする（写真アプリの取り込みでもよい）。PC の録画は「ビデオ」→「キャプチャ」にある
- 置き場所は**リポジトリの外**の `%USERPROFILE%\line-rental-demo-video\raw\`（ファイル名は自由）。個人の画面が映るので、リポジトリには入れない（公開リポジトリに写る）
- 置いたらチャットで知らせる

## 編集の方針（Claude）

- Remotion でコードから書き出す。プロジェクトはリポジトリの外（`%USERPROFILE%\line-rental-demo-video\`）に置き、素材と一緒に管理する
- 1920×1080・音なし・字幕だけ（音を出さずに見られる前提）。字幕と時刻のカードの色はテーマのトークン（`src/constants/theme.ts` のライト）に合わせる
- 打っている間は早送りし、返事が届いた画面で止めて字幕を載せる。スマホの画面は端末の枠の中に置き、PC の画面は確定のまわりを拡大する
- 隠すもの: 管理画面の右上のメールアドレス。ほかに映り込みがあれば足す

### 構成と字幕の案

時間は目安。字幕の言い回しは素材を見てから詰める。

| 時間 | 画面 | 字幕の案 |
|---|---|---|
| 0:00〜0:06 | タイトル | LINE の物件問い合わせに、閉店後も AI が一次対応する |
| 0:06〜0:12 | 夜のスマホ: あいさつ | 夜 22:40。お店はもう閉まっている（時刻は素材のもの） |
| 0:12〜0:32 | 条件を送る → 7件 | 「静かなところがいい」は「できれば」の条件になる／外せない条件で絞り、できれば の条件で並べる |
| 0:32〜0:50 | オートロックも絶対 → 0件 → 提案 | 条件が厳しすぎると0件／ふつうの検索ならここで行き止まり／どの条件を緩めると何件増えるかを計算して聞く |
| 0:50〜0:58 | 条件を変える → 7件 | |
| 0:58〜1:10 | やっぱり2階以上は必須 → 5件 | 途中の心変わりもそのまま受ける |
| 1:10〜1:25 | 内見 → 候補日 → 仮受付 | 内見の希望日まで受け付ける。確定は人がする（AI は確定しない） |
| 1:25〜1:30 | 時刻のカード | 翌朝 10:05 |
| 1:30〜1:48 | PC: 朝の一覧 → 仮受付 → 確定 | 担当者の朝の仕事は「確定するだけ」／（この動画では開発者が担当者役） |
| 1:48〜1:54 | スマホ: 確定が届く | |
| 1:54〜2:00 | 締め | 数字（到達率・全条件で絞る方式との差・禁止回答の検出率・1会話の費用）と QR。数字は README の仕上げで決まった値に合わせる |
